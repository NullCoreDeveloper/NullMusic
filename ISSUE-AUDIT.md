## Changes ready for review

- **Home selection:** Hero filtering excludes hidden songs and blocked artists across recent, account, library, and recommendation sources. Library/account ordering changes on refresh. Quick Picks now apply the same exclusions before taking candidates, including fallback lists, and the loaded feed responds to preference/hidden-ID changes. [HomeViewModel.kt](app/src/main/kotlin/com/music/echo/viewmodels/HomeViewModel.kt), [QuickPickSongs.kt](app/src/main/kotlin/com/music/echo/utils/QuickPickSongs.kt), [HeroCarouselSongs.kt](app/src/main/kotlin/com/music/echo/utils/HeroCarouselSongs.kt).
- **Radio queues:** Deduplicate within/across continuation pages while preserving intentional repeats in ordinary playlists; skip duplicate-only continuation pages with bounded retries and loop detection. [YouTubeQueue.kt](playback/src/main/kotlin/echo/music/iad1tya/playback/queues/YouTubeQueue.kt), [RadioQueuePageFilter.kt](playback/src/main/kotlin/echo/music/iad1tya/playback/queues/RadioQueuePageFilter.kt).
- **Playback/download resolution:** A cached stream stores its HTTP headers and absolute server expiry. Fresh, cached, preloaded, download, and export requests reuse those headers. Downloads previously compared a duration with the current epoch time, causing repeated resolution. Preloading now respects server expiry; video IDs containing underscores retain their cached quality correctly. [ResolvedStream.kt](app/src/main/kotlin/com/music/echo/playback/ResolvedStream.kt), [DownloadUtil.kt](app/src/main/kotlin/com/music/echo/playback/DownloadUtil.kt), [MusicService.kt](app/src/main/kotlin/com/music/echo/playback/MusicService.kt).
- **Download scheduling:** Registered Media3's PlatformScheduler service in [AndroidManifest.xml](app/src/main/AndroidManifest.xml), matching the [official scheduler setup](https://developer.android.com/reference/androidx/media3/exoplayer/scheduler/PlatformScheduler).
- **Playback lifecycle/crossfade:** Task removal stops active/fading players together when configured, clears foreground playback, and releases secondary players. Requested buffering playback stays active when stop-on-clear is off. Crossfade reads live repeat/shuffle state, detaches listeners before modifying the outgoing player's repeat state, and waits for incoming readiness before fading. [PlaybackTaskRemoval.kt](playback/src/main/kotlin/echo/music/iad1tya/playback/PlaybackTaskRemoval.kt).
- **MP3 export:** A serialized queue keeps an album export alive until all jobs complete and rejects duplicate song requests. Notification and storage controls cancel queued/running exports, HTTP transfers, FFmpeg work, and output copying. Temporary files and progress are cleaned up, filesystem output is staged before replacement, and foreground-service timeout stops export work. Android requires timeout handling for time-limited service types. [Service reference](https://developer.android.com/reference/kotlin/android/app/Service#onTimeout(kotlin.Int,kotlin.Int)). [AudioExportService.kt](app/src/main/kotlin/com/music/echo/playback/AudioExportService.kt), [ExportTaskQueue.kt](app/src/main/kotlin/com/music/echo/playback/ExportTaskQueue.kt), [StorageSettings.kt](app/src/main/kotlin/com/music/echo/ui/screens/settings/StorageSettings.kt).
- **Lyrics:** Synced lyrics resume following after four seconds of idle manual scrolling, except during selection. Actual parsed timing determines synced behavior: all-zero timestamps remain readable and metadata brackets do not cause automatic scrolling. Provider selection also recognizes actual timing. [Lyrics.kt](app/src/main/kotlin/com/music/echo/ui/component/Lyrics.kt), [LyricsUtils.kt](lyrics/src/main/kotlin/echo/music/iad1tya/lyrics/LyricsUtils.kt).
- **Settings and lists:** Corrected settings-search routes and removed missing-page entries. Downloaded songs get their own sort preferences, defaulting to download date descending. Queue controls use an equal-width row. Android Auto artist results request a grid with their existing artwork.
