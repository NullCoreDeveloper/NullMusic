## 🎵 О проекте

**NullMusic** — это минималистичный медиаплеер с открытым исходным кодом, созданный для удобной организации и воспроизведения аудиофайлов. Приложение разработано с упором на производительность и удобный пользовательский опыт.

## 🚀 Основные возможности

- **Прямое воспроизведение:** Быстрый доступ к публичным аудиопотокам через единый интерфейс.
- **Кэширование данных:** Возможность локального сохранения аудио для снижения нагрузки на сеть и доступности офлайн.
- **Миграция метаданных:** Удобный импорт и экспорт ваших плейлистов из сторонних платформ.
- **Синхронизированные тексты:** Точное отображение доступных текстов композиций.
- **Анализ аудио:** Встроенная интеграция с сервисами идентификации треков по звуковой сигнатуре.
- **Фоновое воспроизведение:** Корректная работа аудиоплеера на уровне системы при выключенном экране.
- **Кастомизация:** Тонкая настройка интерфейса, поддержка динамических цветов (Material You) и темной темы.

## 📥 Установка

1. Перейдите в раздел **Releases** на GitHub.
2. Скачайте последнюю версию APK-файла (`Universal`).
3. Установите на свое Android-устройство (может потребоваться разрешение на установку из неизвестных источников).
